# Pedidos e cobertura

| Pedido | Implementação / limite |
|---|---|
| Água em Évora | Pesquisa OSM de candidatos; sem inventário verificado |
| Lojas e antiquários | Fluxo de proposta voluntária; sem parceiros reais |
| Supermercados no percurso | Filtro e pesquisa por nome; sem preços atuais |
| Paragens culturais e vistas | Consulta Wikipédia; sem certificação do melhor cenário |
| Percurso e Google Maps | Ordem manual ou estimativa de proximidade, exportação por partes e etapas |
| APIs | Overpass, Open-Meteo, Wikipédia e URLs Google Maps |
| Recuperação de falhas | Tempo limite, validação de respostas, dados guardados com data, texto alternativo |
| Compatibilidade | Interface adaptável, localização opcional, partilha/cópia com alternativa |
| Android/PWA | Manifesto e interface offline; instalação no dispositivo por verificar |
| APK | Não construído ou assinado; requer decisão e testes próprios |
| Investigação | Relatório de oito páginas; evidência recordada e hipóteses identificadas |
| Repositório e publicação | Repositório autónomo, verificações e GitHub Pages |

## Evolução
Verificar pontos e acessos no terreno; recolher consentimento das lojas; entrevistas neutras; avaliação heurística; testes com utilizadores; só depois avaliar serviço operacional e distribuição Android. A aplicação não deve prometer preços, água ou acesso que não consegue confirmar.
