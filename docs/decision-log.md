# Decisões do projeto

| Decisão | Razão |
|---|---|
| Português europeu na aplicação | Pedido do autor e contexto da UC |
| Repositório autónomo | Separar a aplicação do portal geral de estudo |
| Água como núcleo | Sinal exploratório recordado sobre descoberta e compra repetida |
| Lojas apenas por adesão | Nenhuma loja foi confirmada |
| Candidatos separados de pontos confirmados | Um mapa não garante água potável gratuita |
| Google Maps por partes | Preservar todas as paragens em dispositivos móveis |
| Falha explícita ou dados guardados com data | Não substituir erros por sucesso fictício |
| APK adiado | A instalação e distribuição exigem origem estável, assinatura e testes reais |

O âmbito futuro mantém supermercados, vistas, acessibilidade e lojas como opções. A priorização não substitui investigação com utilizadores.
