# Public HCI project agent rules (13 November 2026)

- This public app is a course project. A demo fountain, shop or location example is not a verified real free-water stop. Every marker must visibly distinguish confirmed open data, unverified user reports and demonstration fixtures.
- Do not infer opening hours, safe drinking-water status, accessibility or travel time from guessed coordinates or stale descriptions. Provide missing/unknown states.
- Preserve privacy; no private coordinates, user location history, student identifiers, account tokens, private API keys or restricted Moodle originals in public assets.
- Keep the interface usable without location permission and on small/mobile screens. Test routes, empty data, denied permissions and graceful offline behavior before claiming success.
- GitHub commits, Pages builds, local PDFs and calendar entries are not proof of course submission, feedback or grades. Source-check the current instructor brief before changing scope.
- No automated academic email or Moodle submission without a specific approved action. Keep professional identity routing and internal approval records out of the public site.
